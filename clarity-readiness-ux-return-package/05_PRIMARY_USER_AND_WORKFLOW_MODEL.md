# Primary User And Workflow Model

Product-wide primary stakeholder: receiving behavioral-health facility and its treatment team.

Primary operator for this slice: central intake coordinator.

Secondary roles evaluated: field responder, sending nurse, clinician reviewer, legal/compliance reviewer, benefits or UR specialist, receiving facility, receiving nurse, placement manager, charge nurse, supervisor, and executive/program leader.

Primary workflow:

Protective-custody referral through readiness, routing, acceptance, and handoff.

Target transitions implemented:

- Ready for clinical/legal review.
- Ready to transmit governed packet.
- Ready for facility acceptance and routing.
- Ready for transport, custody transfer, and handoff.
