# Target Information Architecture

## Case Dependency Map workspace

1. Case selector.
2. Target transition selector.
3. Scale scenario selector.
4. Primary blocker summary.
5. Freshness and permission scope.
6. Filters.
7. Visual dependency map.
8. Structured equivalent table.
9. What changed digest.
10. User-facing activity history.
11. Compliance/provenance summary.
12. Existing workspace links.

## Resolution pattern

The map never duplicates data entry. Each item links to the existing workspace where the work is completed.
