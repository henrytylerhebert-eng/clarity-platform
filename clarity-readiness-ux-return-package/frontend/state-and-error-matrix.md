# State And Error Matrix

| State | UI treatment |
|---|---|
| No blocker data available | Primary blocker fallback text |
| Insufficient evidence | Primary summary fallback |
| Stale data | Freshness value and filter |
| Unauthorized or restricted detail | Placeholder source text |
| Unknown | Distinct node status |
| External wait | `external-wait` class and wait filter |
| Non-blocking warning | `warning` class and status badge |
| Not applicable | `not-applicable` class |
