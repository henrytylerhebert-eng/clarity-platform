# Accessibility And Responsive Spec

Implemented:

- Native select filters.
- Keyboard-reachable buttons.
- Visible focus styles.
- Text labels for status and severity.
- Structured table equivalent to the visual map.
- Announced visible count through `aria-live`.
- No hover-only required content.

Manual verification still required:

- Screen-reader pass with VoiceOver or NVDA.
- 390px mobile visual inspection.
- Zoom/reflow review.
- Reduced-motion review.
