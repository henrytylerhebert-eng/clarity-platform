# Clarity Experience Architecture v1.0

## One Clarity, multiple governed representations

```text
                    CLARITY
                       │
                GOVERNED WORLD
                       │
      ┌────────────────┼─────────────────┐
      ▼                ▼                 ▼
     WORK           HISTORY           EXPLORE
      │                │                 │
 traditional       temporal        relationships
 precision UI      reconstruction      2D first
      │                │                 │
      └───────────┬────┴───────┬────────┘
                  ▼            ▼
                 FLOW       ASK CLARITY
             operations       language
```

Spatial is a later renderer inside Explore.

## Work

Purpose: **do the work**

Characteristics:

- familiar operational UI;
- forms, tables, queues, inspectors;
- authorized mutation;
- Case context preserved;
- precision over spectacle.

## History

Purpose: **understand time**

Supports:

- as-of view;
- compare two moments;
- event sequence;
- effective vs recorded time;
- decision supersession;
- barrier intervals;
- PendingDischarge interval;
- continuity windows.

## Explore

Purpose: **understand relationships**

2D first.

Can render:

- decisions;
- evidence;
- plans;
- barriers;
- destinations;
- organizations;
- authority;
- continuity relationships.

Selecting a node opens a conventional inspector.

Graph layout is not truth.

## Flow

Purpose: **understand operational movement**

Examples:

- queue vs flow view;
- phase movement;
- lane bottlenecks;
- waiting states;
- barrier aging;
- cross-Case operational demand.

Flow must consume governed cross-Case data. Do not fake production Flow from localStorage.

## Ask Clarity

Purpose: **ask the world**

Initial verbs:

- Find
- Explain
- Compare
- Trace
- Summarize
- Show changes
- Show missing/unknown evidence

Command execution comes later through governed available-command projection and human authority.

## Representation switching

Representation follows the question.

Case-level example:

`Work | History | Explore`

Operations example:

`Queue | Flow | Explore`

No global “Classic Clarity vs 3D Clarity” product split.
