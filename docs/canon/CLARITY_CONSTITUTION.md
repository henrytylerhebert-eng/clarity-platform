# Clarity Constitution v1.0

## 1. Truth

Clarity may represent different kinds of knowledge, but may not silently collapse them.

Canonical epistemic classes:

- **FACT** — source-backed occurrence or condition.
- **OBSERVATION** — what an identified source observed at a point in time.
- **CLAIM** — what a person/system/organization reports.
- **INFERENCE** — interpretation beyond directly recorded evidence.
- **DECISION** — consequential determination by an authorized actor or external authority.
- **PLAN** — intended future course.
- **PREFERENCE** — expressed choice of the person or authorized representative.
- **DERIVED STATE** — deterministic computation over governed source inputs.

Prohibited silent promotions:

- Claim → Fact
- Observation → Decision
- Inference → Fact
- Plan → Actual
- Preference → Clinical Decision
- Derived → Decided
- Suggested → Assigned

## 2. Time

Every material state or relationship must be answerable as:

> true as of when?

Where relevant, preserve:

- effective time;
- recorded time;
- received time;
- correction/supersession time;
- evaluation time.

Do not overwrite longitudinal history merely to simplify the current-state screen.

## 3. Authority

Identity, role, visibility, and authority are distinct.

A complete authority model distinguishes:

- SEE
- DO
- REVIEW
- DECIDE
- OWN

Visibility never creates decision authority.

AI never creates authority.

## 4. Provenance

Material facts, observations, claims, decisions, derived states, and relationships must retain enough lineage to answer:

- Where did this come from?
- Who recorded or decided it?
- Under what rule/policy?
- What was known at the time?
- What superseded it?
- What remains unknown?

## 5. Tenancy

Every governed operation and projection respects organization/facility scope and applicable disclosure boundaries.

A graph edge can leak restricted information just as easily as a field.

## 6. Commands

Consequential state changes occur through governed commands.

A command must have:

- actor;
- authority;
- scope;
- preconditions;
- source/evidence requirements;
- effective time;
- recorded time;
- idempotency/conflict behavior;
- governed event output;
- audit trail;
- correction/supersession path.

UI and AI do not write canonical state directly.

## 7. Derived state

Derived state is recomputed from governed inputs.

It is not directly mutated.

Examples:

- JourneyPhase
- PendingDischarge
- TransitionReadiness
- barrier age
- longitudinal Care Journey projection

## 8. UI

The interface is a projection of governed truth, not the source of truth.

Work is the precision operating surface.

History reconstructs time.

Explore explains relationships.

Flow explains operational movement.

Ask Clarity provides language access to Query / Trace first and governed Command later.

## 9. AI

AI is a governed participant.

AI may:

- find;
- summarize;
- compare;
- explain;
- trace;
- identify missing/unknown evidence;
- create clearly labeled candidate inferences/proposals.

AI may not silently:

- establish clinical fact;
- establish legal authority;
- establish payer truth;
- make a qualified-human decision;
- infer actual discharge;
- infer causal blame;
- mutate the database outside the governed command path.

## 10. No-collapse rules

- Person ≠ Access Case
- Access Case ≠ Episode
- Episode ≠ Longitudinal Care Journey
- Acceptance ≠ Admission
- Plan ≠ Fact
- Planned discharge ≠ Actual discharge
- Clinical recommendation ≠ Payer authorization
- Payer authorization ≠ Clinical appropriateness
- Available care ≠ Appropriate care
- Patient preference ≠ Clinical recommendation
- Diagnosis ≠ Incapacity
- Clinical stabilization ≠ Clinical discharge readiness
- Clinical discharge readiness ≠ Transition readiness
- Transition readiness ≠ Actual discharge
- Actual discharge ≠ Successful continuity
- Prescription fill ≠ Medication adherence
- No observed event ≠ proof the event did not occur
- High support need ≠ high psychiatric acuity
- Missing ≠ No
- Unknown ≠ Not applicable
