# Product Studio Prototype Release Notes

## Added

- Product Studio navigation for the demo `All workspaces` and `Program Director` views.
- Synthetic registry records for built, candidate, and parked concepts.
- Product, Build, and Run lenses.
- Registry search and lifecycle filters.
- Impact details, decision history, visibility boundary, and human next-action copy.
- Focused app test for navigation, lens switching, and Parking Lot filtering.

- External integrations, public publication, or third-party analytics.
