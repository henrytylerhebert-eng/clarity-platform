# Mock-Use Cohorts

This folder contains synthetic role-play cohorts for demonstrations, training, and workflow review.

These records are **not** canonical app seed data and are **not** live product fixtures. They should not be imported into production systems or mixed with real patient information.

## Current Cohorts

| File | Purpose | Status |
| --- | --- | --- |
| `nbc-sitcom-inpatient-admits.json` | Six fictitious inpatient-admission scenarios for Clarity process, chart-draft, and UR training. | Synthetic mock-use clone only |

## Guardrails

- No real PHI.
- No real facility, police, payor, or patient event.
- Diagnoses are provisional training drafts.
- Chart and utilization-review language requires qualified human review.
- Legal-status language requires counsel validation.
