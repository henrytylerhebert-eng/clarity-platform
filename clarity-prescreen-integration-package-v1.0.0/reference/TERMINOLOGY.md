# Terminology

| Term | Package meaning |
|---|---|
| Prescreen | Brief field/community/hospital assessment and orchestration process before authorized hospital review/acceptance. |
| Central Intake | Receiving coordination function that reviews, requests, routes, and records facility response. |
| MAR | Medication Administration Record. |
| TAR | Treatment Authorization Request. |
| Willing | Patient expresses willingness; does not by itself prove formal-voluntary eligibility. |
| Non-opposed / noncontested candidate | Patient does not object, but knowing/voluntary consent is not established; final status belongs to authorized hospital role. |
| Oriented x4 | Separate observations for person, place, time, and situation. |
| Formal-voluntary prescreen gate | Owner-defined launch rule requiring all four domains oriented before routing to formal-voluntary review. Not a universal capacity determination. |
| OPC | Order for Protective Custody; exact jurisdictional workflow requires approved rule profile. |
| PEC | Physician Emergency Certificate in the Louisiana context; exact signer/transport rules require approved current profile. |
| CEC | Coroner/second emergency certificate terminology used in the Louisiana workflow; exact current legal term and process require counsel/profile validation. |
| Secured behavioral-health transport | Clarity operational category requiring authority, trained personnel, supervision/custody, approved method/destination, and handoff. Not synonymous with restraint. |
| Packet readiness | Enough accepted evidence for a named next review target. Not admission acceptance. |
| Facility profile | Approved versioned configuration derived from facility/jurisdiction sources. |
| Source statement | A material fact linked to the person/document/system that supplied it. |
| Supplement | Post-attestation addition/correction that preserves the prior assessment version. |
