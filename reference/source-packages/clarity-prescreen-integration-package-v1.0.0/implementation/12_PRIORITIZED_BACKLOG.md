# Prioritized Backlog

## P0 — Core vertical slice

- Prescreen contracts and state machines.
- Prescreen service/persistence.
- Start/guided/review/attest UI.
- Central Intake receive projection.
- Synthetic end-to-end scenario.
- Tenant/authority/audit verification.

## P1 — Operational completion

- Communications/tasks.
- Versioned supplements.
- Packet requirements and immutable packet versions.
- Authorized review and facility response.
- Transport qualification and custody.
- Accessibility/mobile hardening.

## P2 — Plug-and-play onboarding

- Facility profile management.
- Consent authority rules.
- Transport provider registry/credential workflow.
- Policy source ingestion and candidate extraction.
- Multi-domain profile approval and testing.

## P3 — External ecosystem

- Secure external referral link/account model.
- First EHR or facility adapter.
- First transport dispatch/status adapter.
- Document exchange acknowledgement.
- Integration reconciliation console.

## P4 — Operating intelligence

- Event projections and aggregate metrics.
- Reassessment timing, request cycles, wait states, packet gaps, transport delays.
- De-identification, suppression, completeness/freshness.
- No patient-level capacity or legal predictions.

## Parking lot

- Predictive disposition/admission.
- Automated legal instrument selection.
- Autonomous facility matching/acceptance.
- Automated medical clearance.
- Broad multi-jurisdiction activation without legal/profile governance.
- Universal facility criteria marketplace.
- Ambient audio capture until privacy, consent, security, and clinical workflow are approved.
