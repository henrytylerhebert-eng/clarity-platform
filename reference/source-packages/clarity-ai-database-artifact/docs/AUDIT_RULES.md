# Audit Rules

## Append-Only Principle

Audit events are immutable. Corrections create new events; they do not overwrite prior events.

## Required Events

### Case
- CASE_CREATED
- CASE_ASSIGNED
- CASE_STATUS_CHANGED
- CASE_CLOSED

### Documents
- DOCUMENT_UPLOADED
- DOCUMENT_VIEWED
- DOCUMENT_CLASSIFIED
- DOCUMENT_REJECTED

## Required Metadata

Each event must include:

- organizationId
- caseId when applicable
- actorType
- actorId
- action
- objectType
- objectId when applicable
- timestamp
- reason for human overrides
- previousStateHash and newStateHash for mutations
- model metadata when AI contributed

## Sensitive-Field Rules

- Member IDs, policy numbers, group numbers, and Medicare identifiers must not appear in clear text in audit event bodies.
- Audit logs may record that a field changed, but not its unencrypted value.
- Screenshots and verification proof must be referenced by document ID rather than embedded in logs.
