# Codex Prompt 04 — Medical Necessity Workbench

Build the medical-necessity workbench from structured facts.

It should organize source-grounded facts into:

- danger to self
- danger to others
- grave disability
- psychiatric deterioration
- functional impairment
- lower level of care tried / unsafe / unavailable
- medical suitability
- collateral confirmation
- active treatment need
- missing documentation

Language rules:

Use:

- “documentation supports clinician review for...”
- “available facts indicate...”
- “requires clinician review”
- “missing data...”

Do not use:

- “patient meets criteria”
- “admission is medically necessary”
- “InterQual says”
- “MCG criteria met”
- “ASAM/LOCUS score is...” unless licensed and configured
